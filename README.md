# Chicago, 1871

An interactive historical atlas of the Great Chicago Fire, with a timeline, researched places and sourced incident accounts.

Open `index.html` to explore, or `research/index.html` for sources and reconstruction limits. This repository contains the published static site.

## Languages

- [English](https://tontontremblay.github.io/chicago-fire-1871/)
- [Français québécois](https://tontontremblay.github.io/chicago-fire-1871/fr.html)

Both editions share the same historical geometry, timeline and evidence. French narration uses original conversational Québec French inspired by the episode’s subjects.
